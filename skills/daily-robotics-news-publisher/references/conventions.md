# Conventions

- Target site: a Chirpy/Jekyll GitHub Pages repo.
- Posts directory: `_posts/digests/`
- Per day: publish two posts (CN/EN).
- Categories: `[Digest, Robotics]`
- Tags:
  - Common: `robotics`, `market`, `arxiv`
  - Language: `cn` or `en`
- Same-day revisions: keep versions by appending `_v2`, `_v3`, ... to filename.

Example output filenames:

- `2026-03-04-robotics-digest-cn.md`
- `2026-03-04-robotics-digest-en.md`
- `2026-03-04-robotics-digest-cn_v2.md`
